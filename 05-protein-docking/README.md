# Phase 5: Protein Structure & Molecular Docking

**Weeks**: 26–31  
**Topic**: Protein Representation, Classical & Diffusion-based Docking  
**Tools**:
1. **ESM-2** (Facebook Research Protein Language Model)
2. **AutoDock Vina** (Classical empirical scoring function)
3. **DiffDock** (Diffusion-based structural pose prediction)

---

## Plan & Objective
- Extract protein embeddings for target sequences using ESM-2.
- Perform ligand docking against target binding pockets using both AutoDock Vina and DiffDock.
- Compare predicted binding poses and metrics against known co-crystallized structures.
