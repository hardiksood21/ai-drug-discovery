# Phase 4: Graph Neural Networks & Binding Affinity Prediction

**Weeks**: 18–25  
**Topic**: Graph Neural Networks (Message Passing, GCN, GAT)  
**Primary Resource**: [PyTorch Geometric (PyG) Docs & Colab Tutorials](https://pytorch-geometric.readthedocs.io/)  
**Dataset**: PDBbind Benchmark Dataset

---

## Plan & Objective
- Represent protein-ligand complex data as molecular graphs (atoms as nodes, bonds/interactions as edges).
- Build a Graph Convolutional Network (GCN) or Graph Attention Network (GAT) in PyG to predict binding affinity ($pK_d / pK_i$).
