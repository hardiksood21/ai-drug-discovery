# Phase 6: Generative Chemistry & De Novo Molecule Design

**Weeks**: 32–39 (Capstone Project)  
**Topic**: VAEs, Diffusion Models, Reinforcement Learning for Chemistry  
**Tools**: Junction Tree VAE, Hugging Face Diffusion Course, AstraZeneca REINVENT

## Capstone Project Architecture
- Build a full generative molecule optimization loop.
- Use **REINVENT** RL agent rewarded by your custom Phase 3 solubility prediction model.
- Generate novel, chemically valid SMILES optimized for high aqueous solubility and desirable QED / synthetic accessibility scores.
