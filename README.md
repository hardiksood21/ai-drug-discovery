## 39-Week Roadmap Rules
- **One resource per phase.** No forks in the road.
- **Pacing**: ~8-10 hours/week. Order matters far more than strict week counts.
- **Goal**: By Month 9, this repository will contain 6 end-to-end projects demonstrating your progression from RDKit basics to generative chemistry.
